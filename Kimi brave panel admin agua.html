Autenticación

POST /auth/register Registrar nuevo usuario 
POST /auth/register
Content-Type: application/json

Body: {
  "ci": "12345678",
  "name": "Juan",
  "surname": "Pérez García",
  "email": "juan.perez@email.com",
  "password": "SecurePass123!",
  "phone_number": "70012345"
}
POST /auth/login Iniciar sesión con Email/Password 
POST /auth/login
Headers:
  user-agent: Mozilla/5.0...

Body: {
  "email": "juan.perez@email.com",
  "password": "SecurePass123!"
}
POST /auth/login-ci Iniciar sesión solo con CI (Rol USER) 
POST /auth/login-ci
Headers:
  user-agent: required

Body: {
  "ci": "12345678"
}
POST /auth/refresh Refrescar access token 
POST /auth/refresh
Body: {
  "refreshToken": "uuid-refresh-token"
}

Responses:
  200 - Nuevos tokens generados
  401 - Refresh token inválido o expirado
POST /auth/logout Cerrar sesión
POST /auth/logout-all Cerrar todas las sesiones
POST /auth/forgot-password Solicitar recuperación de contraseña 
POST /auth/forgot-password
Body: {
  "email": "user@example.com"
}
POST /auth/reset-password Restablecer contraseña 
POST /auth/reset-password
Body: {
  "token": "recovery-token",
  "newPassword": "NewPass123!"
}
GET /auth/google Iniciar login con Google
GET /auth/google/callback Callback de Google

Usuarios

GET /users Listar usuarios con filtros y paginación Bearer 
GET /users
Query params:
  limit: number (default: 10)
  offset: number (default: 0)
  name: string (búsqueda parcial)
  surname: string (búsqueda parcial)
  ci: string
  email: string
  status: boolean
GET /users/{id} Obtener usuario por ID Bearer
PATCH /users/{id} Actualizar usuario Bearer 
PATCH /users/{id}
Body: {
  "email": "nuevo@email.com",
  "phone_number": "70012345",
  "profile_img": "url",
  "status": true
}
DELETE /users/{id} Desactivar usuario Bearer
POST /users/{id}/roles/{role} Asignar rol a usuario Bearer

Facturas

GET /invoices Listar facturas con filtros Bearer 
GET /invoices
Query params:
  limit, offset, isPaid,
  ownerCi, morosos (impago > 3 meses)
GET /invoices/morosos Obtener lista de morosos Bearer
GET /invoices/{id}/qr Generar código QR BNB para pago Bearer 
GET /invoices/{id}/qr
Response: {
  "qrId": "ACJSS1231",
  "qrImage": "base64_string...",
  "expiresAt": "2026-01-27T00:00:00.000Z"
}
GET /invoices/{id}/qr-status Verificar estado de pago del QR Bearer 
GET /invoices/{id}/qr-status
Response: {
  "status": "PAID",
  "isPaid": true
}
POST /invoices/webhook/bnb Webhook BNB (Callback) Bearer 
POST /invoices/webhook/bnb
Body: {
  "event": "payment.completed",
  "qrId": "ACJSS1231",
  "transactionId": "txn-123",
  "amount": 125.00,
  "currency": "BOB",
  "paidAt": "2024-06-16T10:30:00Z",
  "payerName": "Juan Pérez",
  "signature": "hmac-signature"
}
POST /invoices/{id}/pay Marcar factura como pagada (Manual) Bearer 
POST /invoices/{id}/pay
Body: {
  "paymentMethod": "CASH" | "TRANSFER" | "QR" | "OTHER"
}
GET /invoices/{id}/json Obtener datos JSON de la factura Bearer
GET /invoices/{id}/pdf Descargar factura PDF Bearer
